RumahBudget — a working household budget site for the fictional Santoso family of four in Jakarta, November 2026: a dashboard with income, spending and savings, a searchable transaction ledger you can add to and delete from, per-category monthly budgets you can edit, a bills tracker with due dates and mark-as-paid, savings goals you can contribute to, a six-month income-vs-spending report with plain-language insights, and three calculators (50/30/20 split, emergency fund, daily allowance). Static files only, no network requests, works on desktop and phone.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
